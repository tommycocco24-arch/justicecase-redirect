# justicecase.ai

The static site for [justicecase.ai](https://justicecase.ai): free, fact-checked case briefs for law students.

Generated by `site/build_site.py` in the Case Brief Writer app; do not edit by hand. Court opinions are public domain and come from CourtListener (Free Law Project). Brief format adapted from Anthropic's law-student plugin (Apache-2.0).
